# pic-bed

基于 GitHub Pages 的个人图床，用 PicGo 上传图片。

## 目录

- `images/`：通用图片
- `product/`：按产品或项目分类
- `blog/`：博客与笔记图片
- `temp/`：临时图片

## 图片地址

仓库启用 GitHub Pages 后，图片地址格式为：

```text
https://SarahXYJ.github.io/pic-bed/<文件路径>
```

测试图片 `images/test.svg`：

```text
https://SarahXYJ.github.io/pic-bed/images/test.svg
```

## PicGo 配置

```text
Repo: SarahXYJ/pic-bed
Branch: main
Path: images/
Custom URL: https://SarahXYJ.github.io/pic-bed
```

Token 请使用仅授权本仓库、具有 Contents 读写权限的 fine-grained personal access token；不要提交 Token 到仓库。
